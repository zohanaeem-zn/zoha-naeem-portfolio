# Responsive Developer Portfolio

A modern and responsive personal portfolio website built using HTML and CSS. The website showcases professional information, technical skills, educational background, and project work in a clean and visually appealing dark-themed interface.

## Features

* Responsive layout using CSS Grid
* Sticky profile sidebar
* About Me section
* Skills showcase with technology icons
* Education timeline design
* Portfolio project cards
* Hover animations and transitions
* Modern dark theme UI
* Clean and organized code structure

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Responsive Design
* CSS Animations & Transitions
